# Spotify UI Clone 🎵

> A responsive Spotify-inspired music streaming interface built from scratch using HTML and CSS.

This project is a frontend recreation of a modern music streaming platform interface, inspired by Spotify's design language. It focuses on building a clean, responsive, and visually engaging user interface using fundamental web technologies.

The project was created as a frontend development and UI design project to practice HTML structure, CSS styling, responsive layouts, and component-like page organization.

---

## ✨ Features

- 🎵 Modern music streaming interface
- 📱 Responsive layout
- 🎨 Spotify-inspired dark UI
- 📚 Your Library section
- 🎧 Music player interface
- 🖼️ Album and playlist cards
- ⏮️ Previous/next navigation controls
- ▶️ Music playback UI
- 🔀 Playback control icons
- 📱 Mobile-friendly layout
- ⚡ Lightweight frontend with no frameworks

## 🎨 Design

The interface follows a dark music-streaming aesthetic with:

- Sidebar navigation
- Music library section
- Playlist and album cards
- Main content area
- Bottom music player
- Responsive layout

The goal was to recreate a polished streaming-platform experience while keeping the implementation simple and focused on HTML and CSS.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ManasSrivastava2005/Spotify-UI-Clone.git
cd Spotify-UI-Clone
```

### 2. Open the project

Simply open:

```text
index.html
```

in your browser.

No build tools, package installation, or backend server are required.
